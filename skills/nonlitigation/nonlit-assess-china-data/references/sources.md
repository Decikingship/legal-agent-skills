## 运行时补齐台账

逐条记录：`source_id / 完整标题 / 发布机构 / 官方URL / 文号或附件名称 / 文件类型 / 公布日 / 施行日 / 效力状态 / 适用业务与地域 / 本次访问时间 / 原文定位 / 替代或废止关系 / 本次用途 / 未解冲突 / lawId平台链接（法规则必填） / 律师复核记录`。

1. 先取实际主体、行业、目的、字段、规模与行为时间，再通过「智合AI搜法」查上位法律、行政法规及配套。把重要数据目录/通知、特殊主体身份等作为必须取得的事实或依据，未知不等于否。
2. 同时查 CD-01、CD-02 及本次相关的 CD-03/CD-04，不只依早期出境路径。按正式文件核验认证制度的施行与配套，若行为跨节点则分段研究。
3. 问答按具体场景、前提和原文定位记录，返回正式义务来源核验。对招聘、员工、家属、客户及总部远程访问分别判断，不跨场景推导豁免。
4. 将“无需履行某项出境手续”与合法处理、必要性、告知/处理依据、影响评估、安全和个人权利等基础义务分开核验。
5. 页面空内容、附件不可得、接口错误和法规未命中分开记录。替代检索仍失败时保留待核来源和负责人，不编造已核结论，不把旧问答当最新规则。
